## Product Source
After our research, we have chosen **ASOS** as our primary data source. Its HTML structure is beginner-friendly for web scraping, which will streamline the script development process.

## Infrastructure
* **Operating System:** 2x Virtual Machines running Linux Mint.
* **Database:** PostgreSQL.
* **Web Server:** Secure Python-based server with HTTPS support.
